Run it

Python 3.10+ and pip install anthropic. Tests and the template baseline need no key.

git clone https://github.com/louanbardou/refund-triage-agent.git
cd refund-triage-agent

python3 -m unittest discover -s tests -t .      # offline checks
python3 run_eval.py --systems b0                # offline baseline

export ANTHROPIC_API_KEY=...                    # live runs
python3 triage.py T06                           # one ticket, full trace
python3 run_eval.py --systems b0,b1,b1d,agent_nr,agent --label main
Limits
  • Fictional shop, author-written tickets, hand-labelled and cross-checked with a rule-based oracle.
  • One small model; deterministic regex checks, no LLM judge.
  • Staff time is modelled from assumptions, not measured.
  • The platform replays recorded runs and calls no model.
