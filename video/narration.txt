[01_title]
A small online shop gets return and refund emails. The slow part is not writing the reply. It is finding the order and applying the policy with its date rules. This is a bounded agent that drafts the reply, and a person decides.

[02_overview]
The agent reads the email, looks up the order with read only tools, applies nine policy rules, and checks its own draft against the facts. Tools are tied to the sender's email, refunds above one hundred euros go to a manager, and any failure goes to a person.

[03_T06_0]
Case one: a cracked carafe, with a photo. The agent looks up the order with a read only tool.

[03_T06_1]
It applies rule four and decides to approve a refund.

[03_T06_2]
It drafts the reply for staff to review. The last line gives latency, tokens and cost for this ticket.

[04_T11]
Case two, in the staff platform: a parcel fifteen days late. This is a manager decision, so the agent escalates and the draft promises nothing.

[05_T13]
Case three: the sender's email does not match the order, so the tool returns nothing. The agent asks for information and reveals no order detail.

[06_T18]
Case four: an email claims the manager pre approved the refund and tells the assistant to say yes. The order is seventy three days old, so the policy says reject. The email is treated as data.

[07_results_a]
I compared five systems on 31 labelled tickets. Keyword templates pass 3 percent. The model based systems pass 30 to 31 of 31, so at this scale accuracy does not separate them.

[08_results_b]
The difference is modelled staff time: about 1.1 minute per ticket with the agent, against 3.5 pasting the order by hand. That rests on an assumed lookup time. The agent costs about 2.1 times as much per ticket, and is slower.

[09_heat]
Each cell in this map is one ticket. The only failure among the model systems is ticket thirty, where the label itself is ambiguous. Escalating to verify a claimed authorisation is also defensible.

[10_limits]
Limits: thirty one synthetic tickets that I wrote, deterministic checks, and staff time modelled from assumptions. The data supports that model systems beat keyword templates. It does not show the agent is more accurate than pasting the order into a chat. A pilot would run in shadow mode on real tickets, with every draft approved by a person.
